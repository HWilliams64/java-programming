# JUnit video starter

Open this starter folder as the folder in the Java Workspace so its project settings apply. It includes an empty Main.java, JUnit in lib, and the project configuration for the editor’s Run Code button. Keep the folder structure and open Main.java as you follow the video.

This project uses Java 21 and Code Runner. The project settings add the included JUnit library when Run Code compiles and runs Main.java. The notebook uses its own dependency cell instead.

The video builds three tests. The first guided practice example includes a fourth test, for zero kits.
