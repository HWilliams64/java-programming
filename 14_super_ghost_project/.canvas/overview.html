Module 14 Overview: Super Ghost Final Project

CSC-239 Java Programming

Overview

Super Ghost brings your Java player, graphical interface, and background work together. The supplied arbiter controls turns and game state; your player reads the shared binary records and submits a letter with a front-or-back choice. You will connect the provided components, test the real interface and packaged application, and record evidence for move rules, responsive behavior, and shutdown.

Key Concepts

  • Front and back moves: evaluate the resulting continuous fragment against the dictionary.
  • Shared binary protocol: preserve the supplied class identities and actual component contracts.
  • Thread ownership: separate background turn selection from required GUI updates.
  • Arbiter checks: test turn discipline, rule boundaries, complete games, and shutdown.
  • Packaged delivery: run the submitted JAR or ZIP contents with their required runtime files.

Outcomes

Upon completion of this module, students will be able to:

  • Use both front and back moves while checking dictionary substring evidence.
  • Preserve the supplied sharedCode types and cooperate with the arbiter’s binary game protocol.
  • Connect the supplied background and GUI callbacks without blocking the JavaFX Application Thread.
  • Verify and package a usable Super Ghost player with the required controls and runtime files.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • How does allowing a letter at either end change the evidence needed for a valid move?
  • What must agree between the supplied shared classes, the player, and the arbiter?
  • What tests show that the complete packaged player is ready, including its interface and shutdown behavior?
