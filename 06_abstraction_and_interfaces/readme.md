A campus system may announce different kinds of signs or calculate different kinds of work through one shared operation. This module defines interfaces that state those operations and uses polymorphism to call the correct implementation. You will also reuse shared state and behavior through a small abstract class. You will finish by writing a generic class that honors an interface while keeping its stored and returned types consistent.

1. [Interfaces and Polymorphism](01_interfaces_and_polymorphism.ipynb) — Implement one interface in two classes and call both through interface-typed references.
2. [Inheritance and Abstract Classes](02_inheritance_and_abstract_classes.ipynb) — Extend an abstract class while initializing its shared state through super.
3. [Generic Classes and Interfaces](03_generic_classes_and_interfaces.ipynb) — Define a generic class that implements a generic interface with consistent method types.
