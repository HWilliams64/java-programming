Module 06 Overview: Abstraction and Interfaces

CSC-239 Java Programming

Overview

A campus system may announce different kinds of signs or calculate different kinds of work through one shared operation. This module defines interfaces that state those operations and uses polymorphism to call the correct implementation. You will also reuse shared state and behavior through a small abstract class. You will finish by writing a generic class that honors an interface while keeping its stored and returned types consistent.

Key Concepts

  • Interfaces: state the operations an implementation promises.
  • Polymorphism: call different implementations through a shared type.
  • Inheritance: reuse and override accessible class behavior.
  • Abstract classes: combine shared implementation with required operations.
  • Generics: keep operation and element types consistent across reusable definitions.

Outcomes

Upon completion of this module, students will be able to:

  • Express a shared operation contract with an interface.
  • Use polymorphism to call different implementations through one declared type.
  • Reuse shared state and behavior through a small abstract base class.
  • Implement a generic class against a stated generic interface.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • What should a caller know about an operation without knowing its implementation?
  • When should related classes share implementation as well as an operation contract?
  • How can one class design work with different element types while rejecting incompatible values?
