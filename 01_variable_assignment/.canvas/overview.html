Module 01 Overview: Variable Assignment

CSC-239 Java Programming

Overview

This module introduces Java through small programs that print messages and work with values. You will choose variable types, calculate results, and clean text with String operations. Then you will read a name, quantity, and price to produce a receipt. Each lesson combines explanatory reading, a narrated video, animated diagrams, runnable examples, and guided and independent practice.

Key Concepts

  • Console output: print clear messages in a chosen order.
  • Variables: name values and choose matching types.
  • Assignment and arithmetic: store and recalculate results.
  • Strings: clean, join, and compare text.
  • Scanner input: read values in a defined order.

Outcomes

Upon completion of this module, students will be able to:

  • Print ordered messages.
  • Declare and update typed variables.
  • Calculate totals.
  • Process names as strings.
  • Read structured input and produce a receipt.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • How does a program turn entered information into a useful message?
  • Why can a stored total stay the same after a quantity changes?
  • How do reading order and text cleanup affect a receipt?
