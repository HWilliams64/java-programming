This module introduces Java through small programs that print messages and work with values. You will choose variable types, calculate results, and clean text with String operations. Then you will read a name, quantity, and price to produce a receipt. Each lesson combines explanatory reading, a narrated video, animated diagrams, runnable examples, and guided and independent practice.

1. [Messages and Java Programs](01_messages_and_programs.ipynb) — Write two Java output statements in the intended order.
2. [Variables and Arithmetic](02_variables_and_arithmetic.ipynb) — Choose types, calculate results, and explain when a stored total needs recalculation.
3. [Working with Strings](03_working_with_strings.ipynb) — Clean a name and build a message using String methods.
4. [Reading Input](04_reading_input.ipynb) — Read a name, quantity, and price in a defined order.

Use the writing cells to explain predictions and results. Try each practice task before opening its answer, and use the animation controls or still diagrams to review a process at your own pace. The [module glossary](terms.md) provides definitions and examples.
