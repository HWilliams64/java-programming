About This Course

Turn programming ideas into working Java programs. You will organize data, design reusable classes, test your work, and build word-game projects. Later modules introduce graphical interfaces and programs that handle tasks concurrently.

The course builds on prior programming experience. Object-oriented design means organizing a program around objects that hold data and provide related behavior.

Course Schedule

The course has 14 weekly modules. Each runs Tuesday through Monday, from September 8 through December 14. Coursework closes December 18 at 11:59:59 p.m. Eastern time. This course is fully online and asynchronous; there are no scheduled class meetings.

  • Open Modules in Canvas. Read and watch the Learning Materials, run the examples, and complete the practice. Then complete the Deliverables listed for that week.
  • Assignments: Assignments are not required for every module. Coding assignments appear in Modules 01–04, 06–08, 10, and 11. Modules 05, 12, and 13 have no coding assignment. Projects replace coding assignments in Modules 09 and 14.
  • Discussions: Modules 01–11 and 14 include a graded discussion. Post your initial response by Friday, then reply to two classmates by Monday. Follow the dates shown in Canvas. The separate Question Board is ungraded, with no participation minimum.
  • Ghost Project in Module 09: Build and test a dictionary-based word-game player. Super Ghost Final Project in Module 14: Bring your skills together in the final word-game project.

Development Environment

Grader Than Workspace is a browser-based development environment and assignment system inside Canvas. A development environment brings together tools for writing, running, and checking code.

  • Code in Canvas: The workspace uses Visual Studio Code and runs in your browser. You do not need to install Java or an editor on your computer.
  • Learning materials: Course content is provided in interactive Jupyter notebooks in Grader Than Workspace, accessed through Canvas Modules. A notebook combines explanations, media, and runnable code. Select the Java kernel, the program that runs a notebook’s code, when using the Java notebooks.
  • Assignments and feedback: Open coding assignments through their Canvas links. The Grader Than autograder is designed to check code and return rapid feedback. Read the activity instructions and use available feedback to revise your work.
  • Revisions: Canvas permits unlimited coding-assignment attempts until December 18. Meet each posted due date for your initial submission.
  • Submit each project in Canvas as a runnable JAR, a file that packages a Java program, or a ZIP containing the JAR and its support files.

Student Learning Outcomes

By the end of this course, you will be able to:

  • Design Java programs using control flow, methods, collections, and object-oriented design.
  • Test Java programs and handle errors and file data.
  • Build graphical interfaces and coordinate concurrent tasks.
  • Integrate and package working Java word-game projects.
