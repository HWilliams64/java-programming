Course Resources

CSC-239 Java Programming

Textbook

No textbook is required. Course content is provided in Jupyter notebooks in Grader Than Workspace, accessed through Canvas Modules.

  • What is a Jupyter notebook? It is an interactive document that combines explanations, images, videos, and runnable code cells. Read, run an example, inspect its output, and experiment in one place.
  • Learning order: Open Modules in Canvas. Read and watch the Learning Materials, run the examples, and complete the practice. Then complete the Deliverables listed for that week.

Writing and Running Code

You will have two main ways to practice programming: directly inside notebooks and inside the Grader Than Workspace IDE.

  • Notebook practice: Many notebook examples and practice problems include code cells where you can write, run, edit, and rerun Java code as you learn.
  • Grader Than Workspace IDE: Grader Than Workspace is a browser-based development environment inside Canvas. It gives you a full coding workspace without requiring any software installation.
  • VS Code experience: The workspace is based on Visual Studio Code, a professional code editor used widely in software development. It provides familiar tools such as files, folders, syntax highlighting, terminals, and code editing support.

Opening the Grader Than Workspace IDE:

  1. Look at the left-side menu in the Canvas course and locate Grader Than near the bottom.
  2. Click the Grader Than option.
  3. Canvas will open a new Grader Than page. Wait about 30 seconds for the Workspace IDE to connect; then you can write and run code in a full IDE.

Assignments

Coding assignments check your understanding of the related lessons. Assignments are not required for every module.

  • Coding assignments: Complete the work listed in Modules 01–04, 06–08, 10, and 11. Modules 05, 12, and 13 have no coding assignment. Modules 09 and 14 have projects instead.
  • Autograder feedback: Grader Than is designed to check your code and provide rapid feedback. Follow the activity instructions, review available results, and revise the parts that need work.
  • Resubmissions: Canvas permits unlimited coding-assignment attempts through December 18. Submit your first attempt by the posted due date.
  • Module discussions: Modules 01–11 and 14 include a graded discussion. Your initial response and two replies have separate deadlines in Canvas.
  • Questions: Use the separate, ungraded Question Board when you need help. Participation there is encouraged, with no required minimum.

Course Projects

Ghost Project in Module 09: Build and test a dictionary-based word-game player. Super Ghost Final Project in Module 14: Bring your skills together in the final word-game project.

Submit each project in Canvas as a runnable JAR, a file that packages a Java program, or a ZIP containing the JAR and its support files.

Use Grader Than Workspace to organize files, run tests, and prepare your project. Begin early so you have time to check the packaged program before uploading it.
