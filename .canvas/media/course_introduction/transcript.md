# CSC-239 Java Programming — course introduction transcript

## Narration

Hi, and welcome to CSC-239, Java Programming, taught by Professor Harris Williams at Bunker Hill Community College. You've written code before, and now you'll build real Java programs. This course is fully online and asynchronous, so you'll work on your own schedule, with a new module every week. Here's what you'll be able to do by the end. You'll design Java programs using control flow, methods, collections, and object-oriented design. You'll test your programs, handle errors, and work with file data. You'll build graphical interfaces and coordinate tasks that run at the same time. And you'll package it all into working Java word-game projects. So how do we get there? Module by module. We start with Variable Assignment: Java types, strings, calculations, and input that produce results. Then Flow Control, where conditions and loops steer your program. In Static Functions you'll write reusable methods with typed parameters and return values. And in Data Structures you'll choose arrays, lists, sets, and maps to organize your data. Then the design work begins. Classes and Objects has you design classes that protect data and provide useful behavior. Abstraction and Interfaces adds interfaces, inheritance, and generics for flexible designs. In Exceptions and Testing you'll handle failures and confirm expected behavior with JUnit. Text File I/O has you read and write text files and search dictionary prefixes. That's everything you need for the Ghost Project: build, test, and package a dictionary-based word-game player. As your skills grow, Functional Programming and Streams brings lambdas and stream pipelines. Binary File I/O saves and restores typed binary data and objects. JavaFX brings layouts, events, and validation to a graphical interface. And Multithreading coordinates concurrent tasks with threads and producer-consumer patterns. Finally, the Super Ghost Project brings it all together in one tested, packaged program. So what does a typical module look like? Read and watch the Learning Materials, run the examples and complete the practice, then complete the Deliverables. Most modules include a discussion, and assignments are not required for every module. When a coding assignment is there, you can resubmit it as many times as you need through December 18. Two milestones anchor the course: the Ghost Project in Module 09, and the Super Ghost Final Project in Module 14. You'll submit each one in Canvas as a runnable JAR, or a ZIP containing the JAR and support files. Now let's look at where that work happens. Everything starts in Canvas. In the course navigation on the left, click Modules to see the course in order. Inside each module, the Learning Materials come first: the readings, videos, and examples. The Deliverables follow, so you always know what to study and what to turn in. There's no textbook to buy; course content lives in Jupyter notebooks. To open them, click Grader Than in that same left-hand navigation. That opens your Workspace right in the browser, already set up for Java, so there's nothing to install. Coding assignments are designed to run through the autograder, which checks your work and returns feedback quickly, so you can fix and resubmit right away. A few things make this course go smoothly. Start each module early, run every example yourself, and ask questions when you get stuck. The Question Board is always open. It's ungraded, there's no minimum, and I'd love to see you there. You can also email me, or schedule office hours using the link on the course home page in Canvas. I am looking forward to seeing what you build. Let's get started with Module 01.
