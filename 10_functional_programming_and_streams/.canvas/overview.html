Module 10 Overview: Functional Programming and Streams

CSC-239 Java Programming

Overview

A roster or order list often needs the same few steps: select entries, transform them, and summarize a result. This module represents a small behavior with a lambda expression or method reference. You will build stream pipelines and explain when their work actually runs and why a consumed stream cannot be reused. You will finish by comparing a safe sequential reduction with its parallel form and testing whether the operation’s rules support that change.

Key Concepts

  • Behavior as a value: use a functional interface, lambda, or method reference.
  • Stream pipelines: select and transform entries while preserving the intended result.
  • Lazy execution: distinguish pipeline construction from terminal processing.
  • Result ownership: separate stream reuse, unmodifiable results, and editable copies.
  • Reduction and parallelism: choose operations with suitable identity and combination rules.

Outcomes

Upon completion of this module, students will be able to:

  • Supply behavior through functional interfaces and lambda expressions.
  • Transform and filter ordered collections through readable pipelines.
  • Use stream lifetimes and result-list editing rules correctly.
  • Combine values with a safe reduction and explain parallel-processing limits.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • What operation does a functional interface promise, and which behavior supplies it?
  • When does a stream pipeline examine its source, and what happens after its terminal operation?
  • Which rules let partial results be combined without changing the intended answer?
