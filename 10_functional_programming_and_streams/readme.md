A roster or order list often needs the same few steps: select entries, transform them, and summarize a result. This module represents a small behavior with a lambda expression or method reference. You will build stream pipelines and explain when their work actually runs and why a consumed stream cannot be reused. You will finish by comparing a safe sequential reduction with its parallel form and testing whether the operation’s rules support that change.

1. [Passing Behavior with Lambdas](01_passing_behavior_with_lambdas.ipynb) — Assign and pass a lambda through a functional interface.
2. [Transforming Collections with Streams](02_transforming_collections_with_streams.ipynb) — Build a map/filter/toList pipeline from an ordered collection.
3. [Stream Lifecycle and Result Lists](03_stream_lifecycle_and_result_lists.ipynb) — Distinguish a stream description, its terminal execution, and a reusable result list.
4. [Reduction and Parallel Streams](04_reduction_and_parallel_streams.ipynb) — Choose a valid identity and associative operation for reduction.
