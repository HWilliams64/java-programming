**Arbiter** - The supplied program that starts and ends the game, announces turns, and checks the rules.
**Game protocol** - The agreed messages and turn rules that participating programs must follow.
**Word fragment** - The current sequence of letters that must remain a prefix of at least one dictionary word.
**Legal move** - One permitted ASCII letter sent in the required format only on the current team’s turn.
**ASCII** - A character standard; the project permits only its ordinary English alphabetic letters as moves.
**Runtime argument** - A String supplied after the program launch command and received in the main args array.
**Runnable JAR** - A Java archive whose entry point lets java -jar start the application.
**Entry point** - The main class recorded in a runnable JAR so java -jar knows which main method starts the application.
**Integration test** - A check that cooperating components work together under their real shared contract.
