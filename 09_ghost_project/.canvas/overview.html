Module 09 Overview: Ghost Project

CSC-239 Java Programming

Overview

The Ghost project brings your Java components together in a complete player. Your team will follow the arbiter’s text messages, use dictionary evidence to choose letters, and respond only on its own turn. You will test both the separate components and their behavior together, then launch the packaged program with a shared-file path. The project guide gives you milestones and acceptance checks for a runnable JAR and its required data.

Key Concepts

  • Game protocol: distinguish announcements, turn requests, and player responses.
  • Dictionary evidence: choose a permitted letter while checking the resulting fragment.
  • Component contracts: use the supplied parser and actual file and dictionary interfaces.
  • Integration testing: verify complete turns and games with the provided arbiter.
  • Runnable JAR: launch the packaged player with its runtime argument and required data.

Outcomes

Upon completion of this module, students will be able to:

  • Trace the arbiter’s text protocol and write exactly one legal response on the team’s turn.
  • Combine the supplied file, parser and dictionary components into a tested Ghost player.
  • Package and launch a runnable JAR with the shared-file path supplied as a runtime argument.
  • Use controlled scenarios and the provided arbiter to verify behavior before submitting the required runnable package.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • What evidence tells your player that it should write a response now?
  • How does a legal letter decision depend on both the word fragment and the dictionary?
  • What must be verified after a working source program has been packaged for submission?
