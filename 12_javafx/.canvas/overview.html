Module 12 Overview: JavaFX

CSC-239 Java Programming

Overview

In this module, you will build and test graphical user interfaces with JavaFX. A graphical interface lets people use windows, text fields, and buttons to interact with a program. You will connect visible controls to Java objects, validate requests before changing stored values, and inspect the actual windows in the Workspace Desktop. The notebook supplies the JavaFX setup and keeps explanations, examples, and practice together.

Key Concepts

  • Windows and content: connect the window, its scene, and the layout that holds its controls.
  • Interface ownership: use the supplied support to create and close windows and keep interface work on its assigned execution thread.
  • Layout and readability: arrange controls with spacing and padding, and check text as a window resizes.
  • Events and state: respond to user actions, change model values, and refresh visible information.
  • Validated forms: check submitted text before changing stored values and give useful correction feedback.

Outcomes

Upon completion of this module, students will be able to:

  • Create, close, and recreate a native JavaFX window using the supplied notebook support; identify its window, scene, layout root, and label.
  • Build a nested layout with readable styling, then resize its window and check spacing, text wrapping, and visible information.
  • Connect a button action to a Java model and visible label; test pointer and keyboard input through the model boundary and disabled state.
  • Build a labeled form that validates before changing its model; test valid, boundary, malformed, and repeated submissions.

Guiding Questions

Use these questions to connect the examples and practice across the module:

  • How do a Stage, Scene and content root work together to show and recreate a native window?
  • How does an action change model state, refresh visible feedback and determine which controls remain enabled?
  • How can a form reject a request while preserving its last accepted value and keeping pointer and keyboard submissions consistent?
