Module 03 Overview: Static Functions

CSC-239 Java Programming

Overview

This module turns repeated Java work into named static methods. You will define typed inputs, return values, and keep calculations separate from output. You will then combine loops, conditions, and String operations to extract content from a nested bracket group. You will build and test small methods that another part of a program can reuse, including tests for empty and unfinished text.

Key Concepts

  • Static methods: name reusable work and call it through a class.
  • Parameters and arguments: distinguish declared inputs from supplied values.
  • Returned results: let the caller choose how to store, combine, or display a value.
  • Pure calculations: separate input-based results from output and other side effects.
  • Nested text: track delimiter depth and return a substring with clear result rules.

Outcomes

Upon completion of this module, students will be able to:

  • Define reusable static methods with typed inputs.
  • Return a result separately from displaying it.
  • Explain numeric parameter copies and local scope.
  • Trace and test a method that scans nested text.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • What information should a method receive, and what should it return?
  • How can you separate a reusable calculation from the action of displaying its result?
  • Which inputs show whether a text method follows its stated result rules?
