Module 04 Overview: Data Structures

CSC-239 Java Programming

Overview

A campus service must organize tour stops, volunteer names, and repeated supply requests. This module starts with fixed-length arrays and then uses ArrayList for sequences whose size changes. You will use sets to identify unique requests and maps to associate each item with its count. You will finish by combining data structures, preserving the order a report needs, and testing empty or repeated input.

Key Concepts

  • Arrays: store a fixed number of ordered, same-type elements.
  • ArrayList: add, replace, remove, and filter ordered entries.
  • HashSet: recognize membership and keep unique values.
  • HashMap: associate unique keys with values and build counts.
  • Collection choices: preserve required order and test boundary cases.

Outcomes

Upon completion of this module, students will be able to:

  • Organize fixed-size data in arrays and changing sequences in ArrayList.
  • Extract unique values with HashSet and retrieve associated values with HashMap.
  • Convert data while preserving the order the task requires.
  • Test empty, repeated, and missing-value cases and justify a collection choice.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • When should the number of stored entries stay fixed, and when should it change?
  • What should happen when the same request appears more than once?
  • Which structures will preserve the order and information a report needs?
