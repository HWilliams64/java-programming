A campus service must organize tour stops, volunteer names, and repeated supply requests. This module starts with fixed-length arrays and then uses ArrayList for sequences whose size changes. You will use sets to identify unique requests and maps to associate each item with its count. You will finish by combining data structures, preserving the order a report needs, and testing empty or repeated input.

1. [Arrays and Traversal](01_arrays_and_traversal.ipynb) — Create and update a fixed-length array using valid indexes.
2. [ArrayList and Changing Size](02_arraylist_and_changing_size.ipynb) — Use ArrayList methods to add, read, replace, and remove text elements.
3. [Sets and Unique Values](03_sets_and_unique_values.ipynb) — Use HashSet membership and change results to identify duplicate requests.
4. [Maps and Collection Choices](04_maps_and_collection_choices.ipynb) — Read and update key/value entries without assuming missing keys have numeric values.
