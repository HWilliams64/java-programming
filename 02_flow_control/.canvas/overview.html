Module 02 Overview: Flow Control

CSC-239 Java Programming

Overview

This module adds decisions and repetition to the Java programs you built in Module 1. You will translate rules into conditions, choose an action from named commands, and repeat work until a clear stopping condition is reached. You will then combine input, decisions, and nested loops to print a report of supply labels. Reading and animated traces explain how each construct works before guided practice and independent programming tasks.

Key Concepts

  • Conditions: compare values and combine Boolean rules.
  • Branches: choose a path with if or switch.
  • Validation loops: reject supplied values and advance toward a valid one.
  • Repetition: use while, do-while, and for with clear stopping conditions.
  • Nested loops: repeat a full set of inner steps and count the resulting labels.

Outcomes

Upon completion of this module, students will be able to:

  • Choose actions using comparisons and Boolean logic.
  • Use a switch for fixed command choices.
  • Validate a sequence of values with a terminating loop.
  • Trace bounded and nested repetition.
  • Test a report at ordinary and boundary inputs.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • How can you explain why a program chose one action?
  • What changes during repetition, and why will the loop stop?
  • Which boundary inputs could expose a wrong comparison or an extra iteration?
