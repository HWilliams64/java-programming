This module adds decisions and repetition to the Java programs you built in Module 1. You will translate rules into conditions, choose an action from named commands, and repeat work until a clear stopping condition is reached. You will then combine input, decisions, and nested loops to print a report of supply labels. Reading and animated traces explain how each construct works before guided practice and independent programming tasks.

1. [Decisions and Boolean Logic](01_decisions_and_boolean_logic.ipynb) — Use comparisons and Boolean logic to choose a branch.
2. [Switch and Branch Choices](02_switch_and_branch_choices.ipynb) — Use a switch statement for a fixed set of commands.
3. [While Loops and Validation](03_while_loops_and_validation.ipynb) — Trace a while loop through its stopping condition.
4. [For Loops and Nested Repetition](04_for_loops_and_nested_repetition.ipynb) — Use a for loop to repeat a bounded task and accumulate a result.
