A visitor pass, a supply bin, and a signup list each keep information that changes through specific actions. This module uses classes to define that state and behavior once, then creates objects with independent values. You will protect state through public operations and explain what happens when references share an object. You will finish by building a small collection that grows while preserving the entries already stored.

1. [Objects and Constructors](01_objects_and_constructors.ipynb) — Define a class with fields, an explicit constructor and an instance method.
2. [Encapsulation and Shared References](02_encapsulation_and_shared_references.ipynb) — Protect a state rule with private fields and guarded public operations.
3. [Building a Growable Collection](03_building_a_growable_collection.ipynb) — Implement ordered addition using a private backing array and logical size.
