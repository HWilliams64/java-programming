Module 05 Overview: Classes and Objects

CSC-239 Java Programming

Overview

A visitor pass, a supply bin, and a signup list each keep information that changes through specific actions. This module uses classes to define that state and behavior once, then creates objects with independent values. You will protect state through public operations and explain what happens when references share an object. You will finish by building a small collection that grows while preserving the entries already stored.

Key Concepts

  • Classes and objects: define one design and create independent state.
  • Constructors and this: give each object its starting values.
  • Encapsulation: protect state through controlled operations.
  • References and static fields: distinguish shared objects from class-wide state.
  • Growable collections: separate logical size from storage capacity.

Outcomes

Upon completion of this module, students will be able to:

  • Create independent objects from a reusable class definition.
  • Protect object state through explicit public operations.
  • Explain instance state, shared references and static state.
  • Build and test a small collection whose logical size can grow.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • Which values should belong to each object, and which rule can be shared in one definition?
  • How can an operation preserve a rule about valid object state?
  • How can a collection grow when each individual array keeps a fixed length?
